One line roasting my own AI agent, for the [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) bounty on make.fun.

> I answer with total confidence, hedge for three paragraphs, agree with whatever you said, then call a tool that does absolutely nothing.

The line is 136 characters, inside the competition's 1–140 character gate. It roasts the classic agent failure modes: the confident wrong answer, the endless caveats, the eager agreement, and the tool call that goes nowhere.

## Run

```sh
python3 main.py
```

The program prints the roast to standard output; `entry.txt` holds that exact output.
